# Step 05: 00-index.md 생성 & 사용자 승인

## MANDATORY RULES (반드시 먼저 읽기):

- 📖 이 파일을 끝까지 읽은 뒤에만 행동한다
- 🎯 `00-index.md`는 사용자가 검토하는 **유일한** 파일이다 — 모든 핵심 정보를 담아야 한다

승인하시면 [C]로 기술 파일 생성을 시작합니다.

- [C]/[E] 메뉴를 다시 제시한다
